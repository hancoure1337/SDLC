## Описание

Система мониторинга информационной безопасности с трёхмерной консолью
оператора. Агенты на компьютерах собирают события безопасности, сервер
обнаруживает по ним нарушения, а консоль показывает инциденты на 3D-модели
здания: атакованный компьютер выделяется в своём помещении.

Тип проекта: Desktop. Технологии: C++, Unreal Engine 5, PostgreSQL.
