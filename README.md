## Описание

Приложение с графическим интерфейсом пользователя, вычисляющее условное
количество совершённых грехов по введённым пользователем данным: дате рождения
и ответам на вопросы утилиты. Результат расчёта и последние введённые данные
отображаются на главной форме.

Архитектура построена по шаблону MVC с активной моделью: модель хранит данные
и выполняет вычисления, самостоятельно оповещая подписчиков об изменении
состояния; представление подписывается на модель напрямую; контроллер
обрабатывает действия пользователя.
